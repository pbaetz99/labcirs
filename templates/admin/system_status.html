{% load i18n %} {% comment %} The system status of the start page of the admin, for superusers. The context is system_status, a cirs.system_status.SystemStatus. It tells how the system is run and never what is reported in it: no number and no text of an incident is on it. A state is a word as well as a symbol and a tint ("Warning:", "Note:", the check mark at a good date), so the colour is never the only sign. Of the backup only the date, the size and the name from the status file are shown, never the folder, and all of it is escaped like any other text. The headings go h2 (the section) and h3 (each topic) under the h1 of the page; each table has a caption and scope, the caption of the ones under a heading is for those who do not see it. {% endcomment %}
